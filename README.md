# Рассадка на экзамене

Streamlit-приложение: схема мест по аудиториям (520, 523-524, 531). Красная точка — занятое место (при наведении фамилия и имя), серая — свободное, пустой кружок — стул, который по схеме не используется.

## Файлы

| Файл | Что внутри |
|---|---|
| `app.py` | интерфейс и график Plotly |
| `seating.py` | логика: геометрия мест, порядок студентов, распределение |
| `data.py` | чтение xlsx (кэш `st.cache_data`) |
| `config.py` | **устройство аудиторий**, пути к файлам, флаг приватности |
| `Экзамен_рассадка_по_аудиториям.xlsx` | по листу на аудиторию: `№ | ФИО | Перцентиль | Примечание` |
| `Списки.xlsx` | общий список; цвет заливки ячейки «Фамилия» — метка студента |

## Правило рассадки

Места заполняются с ряда 1 (у доски), в ряду — слева направо. В боковой панели можно переключить:

- **Какие места занимать**: «По схеме аудитории» (по умолчанию, из `config.py`), «Через одно место», «Подряд, все места».
- **Порядок студентов**: по рейтингу (перцентилю, ИУП в конце; по умолчанию), по алфавиту, как в листе.
- **Учитывать цветовые метки** (включено): 🔴 красные → первые ряды, 🟡 жёлтые → следующие, нейтральные → дальше, 🟢 зелёные → в конец. Внутри группы — выбранный порядок.

Если студентов больше, чем мест, приложение показывает ошибку с числами и ничего не обрезает.

## Настройка аудиторий

В `config.py` у каждой аудитории — список парт ряда слева направо (`Desk(seats, use)`: сколько стульев и на какие сажать) и число рядов. `rows=None` — подобрать число рядов автоматически и добавить `extra_rows` пустых сзади.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется http://localhost:8501.

## Приватность

В xlsx — реальные ФИО и метки о списывании. **Не публикуйте их в открытом репозитории.**

- Рекомендуемый вариант: **приватный** репозиторий на GitHub, xlsx лежат в нём.
- Если репозиторий публичный — раскомментируйте `*.xlsx` в `.gitignore` (тогда данные в облако не попадут, и приложение покажет ошибку «файл не найден»).
- `SHOW_INITIALS_ONLY = True` в `config.py` — в подсказке и таблице будет «Фамилия И.» вместо «Фамилия Имя».
- Цветовые метки на сайте не показываются — они влияют только на порядок мест.

## Деплой в Streamlit Community Cloud

1. Создайте **приватный** репозиторий на GitHub и запушьте проект (вместе с xlsx):
   ```bash
   git init && git add . && git commit -m "Рассадка на экзамене"
   git branch -M main
   git remote add origin git@github.com:<user>/<repo>.git
   git push -u origin main
   ```
   Перед `git commit` проверьте `git status`: не должно быть `.venv/`.
2. Зайдите на https://share.streamlit.io, войдите через GitHub и разрешите доступ к приватным репозиториям (Streamlit попросит отдельное разрешение).
3. **Create app** → деплой из GitHub: репозиторий, ветка `main`, файл `app.py`. В *Advanced settings* выберите Python 3.12 или новее.
4. **Deploy**. Зависимости поставятся из `requirements.txt`.

### Как ограничить доступ

- Приложение из **приватного** репозитория по умолчанию приватное: открыть его могут только те, кого вы пригласили.
- Откройте приложение → **Share** (справа вверху) → впишите email проверяющих → **Invite**. Им нужно войти в Streamlit под этим email (Google или GitHub).
- В том же меню **Share** проверьте, что *«This app is public and searchable»* выключено.
- Ограничения бесплатного тарифа на число приватных приложений меняются — проверьте актуальные в [документации](https://docs.streamlit.io/deploy/streamlit-community-cloud/share-your-app).

Чтобы обновить данные — замените xlsx в репозитории и сделайте `git push`: приложение перезапустится само, кэш сбросится по дате изменения файла.
